↻版本更新紀錄V1.1 ～ V1.9｜查看歷次修改內容 展開／收合 ⌄

以下記錄各版新增或調整的功能。計算及判定均使用目前 V1.9 的規則，不會依舊版公式重新切換。

  1. V1.1

    手機、電腦與資料紀錄

    建立響應式網頁，加入機種名稱、RAM 容量與數量、Short idle／Long idle／待機／S5 欄位；支援本機儲存、CSV 匯出，提供 GitHub Pages 發布說明。

  2. V1.2

    測試分類及第一版加權公式

    新增 CEL、Energy Star 9.0；RAM 限制為 8／16／32 GB、1／2 條。新增四項換算（當時為「原始值 ÷ 12 × 1000」）與加權計算，當時以 AAA／BBB／CCC／DDD 命名。

  3. V1.3

    修訂換算公式、建立 SPEC 管理

    將 AAA／BBB／CCC／DDD 改名為 Short idle*／Long idle*／S3*／S5*，公式改為「原始值 × 12 ÷ 1000」；新增 V74／V75／V77、分類及 RAM 組態對應的 36 組 SPEC，分離本機草稿與網站正式共用 SPEC。

  4. V1.4

    PASS／FAIL 與自動／手動換算

    待機欄位統一為「S3或Modern Standby」；SPEC 每組只填加權結果上限。結果 ≤ SPEC 顯示 PASS，超過顯示 FAIL，缺少值則未判定；星號換算可切換自動或手動輸入。

  5. V1.5

    固定 mW、介面放大與手機優化

    原始量測值固定顯示 mW，SPEC 標示依需求顯示 KW/Hr；放大 PASS／FAIL 判定、統一原始輸入與換算欄位尺寸，改善手機單欄操作與 GitHub Pages 發布流程。

  6. V1.6

    簡易帳號密碼登入

    新增登入表單、帳密錯誤提示、工作階段記憶與登出按鈕；原有計算、SPEC 與紀錄功能維持不變。登入只在前端檢查，不具有真正的資料存取保護。

  7. V1.7

    版本紀錄與使用排查資訊

    在頁面最下方新增預設收合的 V1.1～V1.7 更新紀錄；增加 GitHub Pages 網站開啟問題的排查說明及頁面載入提示，保留 V1.6 登入與所有計算功能。

  8. V1.8

    設計者、尺寸分類與授權共用 SPEC

    頁首新增「RD411-Evan Wu」；機種系列由 V74／V75／V77 改為 14／15／17 吋，保留機種名稱自動判斷及舊版紀錄相容。SPEC 改用管理密碼授權後寫入 Cloudflare D1 共用資料庫；其他使用者每 30 秒及重新開啟頁面時同步讀取。不再依賴個人草稿更新正式 SPEC。

  9. V1.9

    免 Cloudflare：GitHub 或 Google 試算表共用 SPEC

    提供兩種使用模式：只用 GitHub 時由有寫入權限者編輯 specs.js，發布後其他人可讀取；Google 試算表模式則以 Apps Script 管理頁和伺服器端管理密碼更新共用 SPEC，計算網頁定期讀取資料。保留 14／15／17 吋、36 組 SPEC、換算、加權、PASS／FAIL、CSV 與登入畫面。

資料安全提醒：一般登入仍只是 HTML／JavaScript 畫面限制，無法保護公開網站。Google 模式的管理密碼於 Apps Script 伺服器驗證，但 SPEC 讀取端點仍公開；請勿存放個資或機密 SPEC。
