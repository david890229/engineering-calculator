04 / SPEC CONFIGURATION

V74 / V75 / V77 SPEC 管理

兩種分類 × 三種 RAM 容量 × 兩種 RAM 數量 × 三個系列，共有 36 組獨立的加權結果 SPEC。

共用 SPEC 不會因其他人輸入測試值而改變。你可以在下方編輯並保存「本機草稿」，但只有把產生的 specs.js 上傳到 GitHub 網站專案，新 SPEC 才會同步給不同裝置的使用者。一般訪客無法直接修改網站的共用 SPEC；GitHub 寫入權限才是正式發布的控制。這個管理區不是密碼保護功能。
